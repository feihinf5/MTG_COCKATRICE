Note
- 2010 Magic Online World Championships 4-0 Extended format deck
- Target low-cost tokens with [**Polymorph**](https://api.scryfall.com/cards/83d274f4-452b-4ff2-b026-83667e9ba98f?format=image) to instantly tutor and cheat out [**Emrakul, the Aeons Torn**](https://api.scryfall.com/cards/67600383-bbb8-411c-b8e6-2296650bc747?format=image) directly onto the battlefield
- Runs zero actual creature cards so that every [**Polymorph**](https://api.scryfall.com/cards/83d274f4-452b-4ff2-b026-83667e9ba98f?format=image) resolve is guaranteed to hit [**Emrakul, the Aeons Torn**](https://api.scryfall.com/cards/67600383-bbb8-411c-b8e6-2296650bc747?format=image)
- Uses non-creature permanents to make target tokens, [**Bitterblossom**](https://api.scryfall.com/cards/8145fed6-6b51-420a-84cf-4ea5e0aa1883?format=image), [**Khalni Garden**](https://api.scryfall.com/cards/1cc6a5e6-0b73-4488-8954-4b168ce7106d?format=image) and [**Mutavault**](https://api.scryfall.com/cards/8ca3c48b-f104-4292-9a4e-2ce87a65893c?format=image)
- Runs 1 copy of [**Murmuring Bosk**](https://api.scryfall.com/cards/7d4f8cc7-3d02-4cf2-920f-2cc32b58f397?format=image) solely so blue fetchlands like [**Misty Rainforest**](https://api.scryfall.com/cards/24a5cc2c-0fbf-4a5f-b175-6e0ffd0d0787?format=image) can fetch a green source to guarantee casting [**Khalni Garden**](https://api.scryfall.com/cards/1cc6a5e6-0b73-4488-8954-4b168ce7106d?format=image) for an instant token
- [**Jace, the Mind Sculptor**](https://api.scryfall.com/cards/0e606072-a3aa-4300-ba90-ec92a721fa76?format=image) to shuffle [**Emrakul, the Aeons Torn**](https://api.scryfall.com/cards/67600383-bbb8-411c-b8e6-2296650bc747?format=image) back into the library if drawn, keeping the combo intact
